# SRS.md — Ware (اقتصاد وأعمال — الخليج)

## Functional Requirements
- FR1: أخبار اقتصادية حسب الدولة (السعودية/الإمارات/قطر/الكويت).
- FR2: تحليلات سوق الأسهم (تداول، دبي المالي، بورصة قطر).
- FR3: أدلة استثمار وعقارات.
- FR4: مقارنة تكلفة معيشة بين مدن الخليج (جدول ثابت يُحدَّث دوريًا).
- FR5: تصنيف "شركات ناشئة واستثمارات".
- FR6: بحث، صفحات أساسية، إعلانات.

## Non-Functional Requirements
- Financial Content Integrity: كل رقم مالي يحمل مصدرًا وتاريخًا (asOfDate) إلزاميًا.
- Disclaimer إلزامي أسفل كل مقال تحليل/استثمار (نص يُصاغ لاحقًا، يحتاج مراجعة قانونية فعلية).
- Freshness: عتبة "بيانات قديمة" = 7 أيام (افتراضي مقترح، بانتظار تأكيد الرقم الدقيق من المستخدم).

## User Stories
US1: كمستثمر مغترب، أريد دليل استثمار عقاري بالسعودية، حتى أفهم الإجراءات قبل القرار.
US2: كباحث عن عمل، أريد مقارنة تكلفة معيشة بين مدن، حتى أقرر أي مدينة أستهدف.

## Use Case — قراءة تحليل سوق
Error Flow: رقم مالي بلا مصدر أثناء المراجعة → يُرفض النشر حتى التصحيح (قاعدة صارمة).
